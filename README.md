# ऑटो रिप्लाई (WhatsApp ऑटो-रिप्लाई + कॉल मैनेजर)

बिना किसी सर्वर के, सिर्फ़ आपके फ़ोन पर चलने वाला Kotlin ऐप।

## क्या करता है
- **ऑटो-रिप्लाई:** WhatsApp की निजी (1-1) चैट में आए संदेश पर नोटिफिकेशन के "Reply" बटन से अपने-आप जवाब भेजता है (`NotificationListenerService`)।
- **ग्रुप चैट अनदेखी:** `Notification.EXTRA_IS_GROUP_CONVERSATION == true` वाली हर नोटिफिकेशन छोड़ दी जाती है।
- **मिस्ड कॉल माफ़ी:** WhatsApp वॉइस/वीडियो कॉल मिस होने पर अलग माफ़ी संदेश भेजता है।
- **कॉल रिजेक्ट:** `CallScreeningService` सिर्फ़ आपकी दी हुई सूची के नंबरों की फ़ोन-ऐप कॉल को 24 घंटे (बदलने योग्य) तक चुपचाप रिजेक्ट करती है। बाकी सब कॉल बजती हैं।
- **सेटिंग्स:** सभी संदेश, डिफ़ॉल्ट (फ़ॉलबैक) जवाब, समय/दिन, रेट लिमिट, समय-आधारित नियम, मिस्ड-कॉल वाक्यांश, लॉग रखने के दिन, सब कुछ ऐप में बदला जा सकता है।
- **SQLite लॉग:** हर जवाब, छोड़ी गई ग्रुप चैट, माफ़ी, ब्लॉक कॉल का रिकॉर्ड; CSV एक्सपोर्ट।
- **हिंदी UI और TalkBack:** पूरा ऐप हिंदी में है; बटन 48dp+, शीर्षक/स्विच के सही सिमैंटिक्स, रंग पर निर्भरता नहीं।

## APK कैसे बनाएँ
1. यह फ़ोल्डर GitHub रिपॉज़िटरी में पुश करें (`push_to_github.sh` स्क्रिप्ट से)।
2. रिपॉज़िटरी के **Actions → Build APK → Run workflow** पर जाएँ (या `main` में पुश होते ही अपने-आप चलता है)।
3. पूरा होने पर **Artifacts** से `AutoReply-debug-apk` डाउनलोड करें और फ़ोन में इंस्टॉल करें।

या Android Studio में फ़ोल्डर खोलकर **Run** दबाएँ।

## पहली बार सेटअप (ऐप के होम स्क्रीन पर भी लिखा है)
1. **नोटिफिकेशन एक्सेस** चालू करें। Android 13+ पर साइडलोड ऐप के लिए विकल्प धूसर दिखे तो: ऐप जानकारी → ⋮ → *Allow restricted settings*।
2. **डिफ़ॉल्ट कॉल स्क्रीनिंग ऐप** चुनें (कॉल ब्लॉक के लिए)।
3. **बैटरी ऑप्टिमाइज़ेशन से छूट** दें।
4. होम पर "ऑटो-रिप्लाई" स्विच चालू करें।

## सीमाएँ (ईमानदारी से)
- कॉल रिजेक्ट सिर्फ़ **फ़ोन ऐप/सिम की कॉल** पर काम करती है, WhatsApp कॉल पर नहीं।
- जवाब तभी जाता है जब WhatsApp की नोटिफिकेशन में Reply बटन हो (म्यूट/हटाई गई चैट पर नहीं)।
- मिस्ड कॉल की पहचान नोटिफिकेशन के टेक्स्ट से होती है; अगर आपके फ़ोन पर पहचान न हो तो सेटिंग्स में "अतिरिक्त वाक्यांश" जोड़ें।
- मिस्ड-कॉल नोटिफिकेशन में Reply बटन न हो तो उसी संपर्क की हाल की चैट नोटिफिकेशन का Reply बटन इस्तेमाल होता है; वह भी न मिले तो लॉग में "कोई Reply बटन नहीं" दर्ज होता है।
- ऑटोमेशन WhatsApp की शर्तों के विरुद्ध हो सकता है; अपने जोखिम पर इस्तेमाल करें।
